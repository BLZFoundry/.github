# BLZ Foundry

**Break the logic. Build the proof.**

BLZ Foundry is an independent Product Foundry for turning brave ideas into useful products, systems, and experiments. AI is one powerful material in the shop—not the boundary around the work.

## How the brand fits together

- **BLZ Foundry** builds products and proof.
- **BLZ Research** learns, tests assumptions, and publishes evidence.
- **Broken Logic Zone** is the philosophy behind the work.
- **BraveLabz** is the origin story.

GT International operating work is intentionally treated as a separate organizational boundary. Reusable product IP can be incubated here; shop-specific data, credentials, integrations, and deployments belong in private GT International repositories.
